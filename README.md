# Welcome to MDLive ✨

A **live** markdown editor with *real-time* preview.

## Features

- **Bold**, *italic*, ~~strikethrough~~, and <u>underline</u>
- Headings, blockquotes, and code blocks
- Emoji picker 😎
- Mermaid diagrams
- Image & video embeds
- Multi-language support
- Dark & light themes
